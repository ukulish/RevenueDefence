RevenueDefence
AI-powered revenue risk analysis and recovery platform.


Features
- AI customer risk analysis
- High / Medium / Low risk classification
- Recovery recommendations
- Recovery status tracking
- SQLite persistence
- Analytics dashboard

Tech Stack
- React + Vite
- Node.js + Express
- Python
- SQLite
- Scikit-learn / joblib

Installation

1. Clone repository
2. Install backend dependencies
3. Install Python dependencies
4. Start backend
5. Install frontend dependencies
6. Start frontend

Backend:
cd backend
npm install
npm run dev

Frontend:
cd frontend
npm install
npm run dev

Open:
http://localhost:5175
